# Vault — приватный мессенджер

Минималистичный мессенджер со сквозным шифрованием. Без телефона, почты и имени: при регистрации
приложение само создаёт для вас уникальный ID, и общение происходит только по нему. Никакие личные
данные никому не передаются.

## Возможности

- **Чаты** — личные сообщения. Контакт добавляется по ID, а имя контакта видно только вам.
  Сообщения от незнакомых ID помечаются как «Неизвестный»: такого собеседника можно добавить
  или заблокировать.
- **Группы** — общие чаты до 200 участников. Владелец группы добавляет и исключает участников,
  меняет название; любой участник может выйти.
- **Настройки** — ваш ID, тема оформления (авто, светлая, тёмная), автоблокировка, автоудаление
  сообщений, список заблокированных, резервная копия и удаление аккаунта.

Звонков нет — только переписка.

## Безопасность

- **Сквозное шифрование.** Сообщения шифруются на вашем устройстве и расшифровываются только
  у получателя. Для каждого сообщения создаётся новый ключ (ECDH P-256 + AES-256-GCM), а подпись
  отправителя (ECDSA) защищает от подделки.
- **Анонимный ID.** ID — это отпечаток ваших ключей шифрования. Подменить ключи собеседника
  незаметно нельзя: приложение всегда сверяет их с ID.
- **Сервер ничего не знает.** Он видит только ID получателя и зашифрованный текст: ни содержания,
  ни отправителя, ни состава групп. Доставленные сообщения сразу удаляются с сервера.
- **Защищённое хранение.** Вся переписка и ключи на устройстве зашифрованы вашим паролем.
- **Автоблокировка и автоудаление** — приложение закрывается при бездействии, а старые сообщения
  удаляются автоматически.

## Дизайн

Чистый минималистичный интерфейс со светлой и тёмной темой и плавными анимациями 60 Гц.
Удобно и на компьютере, и на телефоне.
